# 记忆星图 · 界面

这一册讲屏幕上每一样东西怎么用、为什么这么做。

## 1.6.1：口令门把手

- 开启 `--token` 后直接打开 `/app`，不再只得到 401 JSON，而是一张不加载脚本的登录卡：
  一个口令输入框、一个「打开星图」按钮；错误口令留在卡上提示，不会把输入的东西带回地址栏。
- 登录成功后种 `HttpOnly` cookie 并回到页面；接口和静态资源仍然只认 cookie / Bearer，
  不会因为「有登录页」就放松 API。
- 登录页独立于星图样式，CSP `default-src 'none'`；它只负责开门，不参与数据渲染。

## 1.0.0：敢卖（诊断与支持）

- **「?」→「复制诊断」**：帮助浮层底部新增按钮，复制一份纯文本报告：版本/构建、宿主或独立引擎、
  当前视图、语言、浏览器 UA、屏幕/DPR、WebGL renderer、图规模、建图耗时、来源数、最近一次页面错误。
- **不包含记忆正文，也不包含本机路径**；来源只写标题与体积，可以整段贴给支持。
- **页面错误**：启动失败或运行时异常会在报告里留前 300 字，方便定位「是不是宿主旧了」。
- **后端对应**：`GET /diagnostics` 与 `npx memory-nebula --diagnose` 输出同一套字段，
  没有界面时也能取；示例模式 `?demo=1` 报告 64 条示例库。

## 0.9.0：说英文（中英双语）

- **语言选择**：`?lang=en` / `?lang=zh` 强制；否则读 localStorage `nebula.lang`，再退到
  浏览器语言（`zh*` 中文，其余英文）。顶栏最右的语言按钮在 `EN` / `中` 之间切换并记住。
- **中文是源文**：代码里写中文，英文模式查表；查不到就显示中文，而不是 `undefined`。
- **覆盖范围**：顶栏、搜索、左栏、筛选、详情、看板、项目卡片、时间轴、证据链、新手三步、
  快捷键、空态、启动错误、toast；记忆正文与工作区名保持原文，不翻译。
- **快照**：`i18n.js` 内联进单文件，离线快照同样可切英文；`/share?lang=en` 直接打开英文。
- **英文排版**：长标签有专用间距与字号；`html.lang-en` 下统计条、来源计数、快捷键面板
  不重叠；820 宽无横向溢出。

## 总览：一张图、三种视图

- 深空星云：每个工作区一簇，节点大小按重要度 + 命中数，颜色按层级（`soul/user/project/lesson/topic/fact/rules`），边的颜色按类型。
- 搜索：命中列表顶端先告诉你「搜了什么、扫过多少条、给了几条最相关」，把与查询重合的词标亮；
  认不出的词单独列一行（「没认出的词：…」），免得把「词没落库」误当成「没有这条记忆」。
- 搜索没有命中时不会只给一句「没有找到」：抬头仍写查询词、扫过多少、没认出的词，正文给出下一步（换更短的词 / 先按工作区筛）。
- 拉远到点被聚合成「光斑」时，点光斑＝下钻进那个项目（镜头飞过去并提示一次），双击空白回到全图。
- 交互：滚轮缩放（鼠标下的点不动）、拖背景平移、拖节点临时钉住、悬停看摘要（并高亮它的全部邻居，鼠标移开就还原）、点击看详情、`/` 聚焦搜索、回车取第一条，命中时沿边打脉冲。
- 无障碍：画布带 `role="img"` 与「记忆星图：N 条记忆，M 条连接」摘要；系统开启「减少动态效果」时跳过生长动画、3D 不自动旋转，直接显示完整图。
- 键盘：`/` 搜索、`↑↓` 在搜索结果里走（右侧星图实时预览）、`Enter` 打开、`1/2/3` 切星云/星系/时间、`e` 定位到选中节点、`r` 重建、`Esc` 关详情。上次用的视图会记在 `localStorage`，下次打开还是那个视图。
- 筛选（左侧下栏）：工作区 / 层级 / 连接类型 / 最小连接强度 / 最低重要度，全部实时生效。
- 记忆来源（左侧上栏）：记忆库个数与条数、已装插件、记忆类插件、技能数、MCP 数，以及一句「记忆本体只读」的声明。
- 详情面板（右侧）：层级/工作区标签、重要度条、正文关键词高亮、关键词 chips、**「这条记忆提到的来源」**（正文里原样出现了哪个技能 / MCP / 插件名，`◆技能 ▣MCP ◈插件`）、连接到的记忆（每条带「为什么连」的证据与权重条）。
- **纠错：把算错的关联按掉**。详情面板每条邻居右侧有一个 `×`（hover 才显形）：
  - 自动推断出来的边 → 记进屏蔽表（`mutes`），以后重建也不会再连；
  - 人工策展的边 → 直接删掉；
- 三种视图共用同一套筛选：工作区 / 层级 / 类型 / 强度 / 重要度，2D 与 3D 的「隐藏 N 条」是同一个数（3D 也实现了 `visibleNodes()`）。
- 筛选把记忆全藏起来时，画面中央会出现「这一屏没有记忆」与回全视图的出口（Shift+F / 左栏「重置筛选」）；被筛掉的簇不会再画光斑。
  - 屏蔽过的关联在左侧「记忆来源」里有「已屏蔽关联 N 条」，点开可以逐条「恢复」；
    误点的当场也能退：提示条会挂一个「撤销」（8 秒内有效，且不会被轮询提醒顶掉）。
  - AI 侧同样的能力：`nebula_link(action="mute" | "unmute", a, b)`。
- **上下文脉络：同一次会话里还写下了哪些记忆**。详情面板会列出这条记忆所属会话里的其它记忆，按「时间上离它最近」排（前后几分钟写下的，往往才是同一条思路里的东西），最多 12 条，点一条直接跳过去。一条记忆单看容易断章取义，配上同一场对话里它旁边的几条，就知道当时在讲什么、后来怎么改的口。
- **出处：写这条记忆的时候，主人当时说了什么**。星图会去读 DSH 自己的会话转写（`$DSH_HOME/sessions/**/session.v4.jsonl.zstd`，其中每个文件是多帧拼接的 zstd，星图自己拆帧解压），取「这条记忆写下来之前最近的一条真人消息（45 分钟内）」，在详情面板顶部原样引用，并标注「出自会话 `xxxxxxxx` · 说过这话 13 分钟后写下」。这是只读的旁证：它不给记忆连边，只回答「这话从哪来」。
- **证据链：问一句「这两条记忆到底怎么连上的」**。左键选中一条，按住 `Shift` 点另一条 —— 图上会亮出一条金色路线（沿途节点标 1、2、3…），底部弹出面板逐步写明每一跳的类型、权重与证据（例如 `keyword · 0.3 · 共享关键词：镜像站`）。找不到就直说找不到，不会绕一大圈硬凑一条路（默认上限 6 跳，代价用 `-log(w)`，所以优先走证据最硬的那条）。AI 侧同一个能力：`nebula_path(a, b)`。2D 星云是看证据链最清楚的视图，3D 里它只是把节点染金、放大 2.2 倍并打脉冲。

  **这条链有两套算法，前端会自己挑**：优先问服务端（`GET /path`，与工具同源的 Dijkstra）；如果服务端的路由还没跟上（比如宿主没重启、`http.js` 还是旧版），就在浏览器里用图数据当场算一条（同样是 `-log(权重)` + 6 跳上限），标题后面会标「（本地计算）」。所以这个功能不依赖服务端版本，页面能画图就查得出链。
- 三种视图（右上角按钮循环切换：`星云` → `星系` → `时间`）：
  - `星云`：力导向聚类的平面星云，边与证据看得最清楚。**节点间距由关系紧密度决定**——先算每对节点的 `pairW`（两点间最强边的权重），再定最小间距 `26 + 44*(1-w)`（没关系的一对 52px 起步），弹簧静止长度同样按 `26 + 96*(1-w)^1.35` 收缩：证据越硬的两点贴得越近，没关系的一对自然疏开。于是强关联结成核、弱连接散在外围，图本身就能读出结构，而不是一层均匀铺开的网格。簇名推到簇外并用细引导线牵回质心。
  - `星系`：真三维（原生 WebGL，零依赖）。**布局＝三维力导向**（Barnes-Hut 八叉树 + 弹簧 + 簇心引力，收敛后写 localStorage 缓存，`LAYOUT_VERSION` 变才重算）；**渲染＝光点**（`gl.POINTS` + `gl_PointCoord` 造核心与晕，加色混合），深度感来自真投影矩阵和视差，不做 bloom 后期，不搞光污染。**来源节点在这一层是「菱形」**：片元里用 L1 距离（`|x|+|y|`）替代圆形半径，并给它更高的最小像素（3.5px 起）和 1.15× 尺寸，所以远看也认得出「这是技能/MCP/插件，不是记忆」。
    - 节点大小：`rWorld = 13 + 重要度*5 + 热度*7`，屏幕上 `clamp(px*1.35, 1.5, 15)`。
    - 交互：左键拖转视角（带累积惯性，松手后按 0.92 衰减再滑一小段）、中键/右键拖平移（沿相机 right/up 向量，屏幕像素按 `2*dist*tan(fov/2)/h` 换成世界距离，1:1 跟手）、滚轮缩放、双击回中；**中键只平移绝不选中**；点节点开详情，悬停出标签。
    - 簇名不压在星团里：从画面中心朝星团方向推到外圈，用一条细引导线连回星团质心，重叠自动往下让位。
  - `时间`：**螺旋星系盘**，半径＝记忆年龄（中心「最近」，外圈越久远），每个工作区占一条旋臂（扭角 1.4π），盘面有厚度（重要度越高越贴盘中层）；年龄环的刻度会自适应：跨度只有几小时/几天时就画 `1/3/6/12 小时前`、`1 天前`，长跨度时自动变成 `N 天`、`N 个月`、`N 年前`；标签按 2.1 弧度错开避免叠在一起；同一个三维相机，拖转/平移/缩放与「星系」一致。
- 12 秒轮询 `/ping` 的 `sig`：别的会话写了新记忆 → 星云自动长出新星星并提示「+N 条记忆」。
- 性能：874 节点 / 3000+ 边，2D 帧间隔中位数 16.7ms（≈60fps）；3D 顶点数据只在布局/筛选/高亮/脉冲变化时重传，相机旋转不碰 buffer；无头软件 GL 下 34fps，真机 GPU 上满帧。
- 缩放/拖动的两个提速手段（`lib/web/render.js`，都**不改变画面质量**）：
  1. **连边批处理**：按「颜色 + 量化透明度」归并成十几条 `Path2D`，每批一次 `stroke`（原来 3000+ 条边各自 beginPath/stroke）。曲线、弧度、透明度都照旧。
  2. **光点贴图缓存**：每种层级色只渲染一次发光球到离屏 canvas，之后全是 `drawImage` 缩放（原来每帧给 940+ 节点各建两个径向渐变）。
  - 实测（无头 Edge + 软件渲染）：连续 40 次滚轮，帧间隔中位 16.6ms、p95 19.4ms、最差 29.6ms —— 全程都是精细画法，没有「先糊后清」的过渡。
  - 曾经试过「交互期贴上一帧的快照 + 直线近似」的偷懒画法，实测更慢而且视觉上明显发糊，已整体撤掉。

**悬停时只「减淡」，不「消失」**：鼠标停在一颗光点上时，非邻居节点降到 45% 亮度、非相邻边降到 34%，被悬停的那颗额外放大 1.7× —— 靠「亮起来」抢注意力，而不是把别人按黑。2D 同步（节点 42%、边 7%），两个视图手感一致。

**来源节点的详情是反过来的**：点开一个带 `mentions` 的来源节点（比如 `meow-memory`），面板顶部会写「谁提到过它 · 22 条记忆 / 分布在 5 个项目」，按项目给出条数（Remote Connect DSH ×13、Definitely Unity ×5…），下面列出提到它的记忆，点一条直接跳过去。这样「这个技能在哪些项目里真的被用过」一眼可查。

**两条独立证据：被提到 ≠ 真被调用。** `mentions` 边只证明「记忆正文里写过这个名字」，所以面板还会补一行「会话里实际调用过 N 次 · 分布在 M 个会话」——从 141 个会话转写的 `tool/call` 事件里数出来：`skill` 工具取 `arguments.name`、`mcp__<server>__<tool>` 取服务器名、`memory_*` / `nebula_*` / `hindsight_*` 这类带前缀的工具名按属主归因（`TOOL_OWNER` / `TOOL_PREFIX`）。实测 `meow-memory` 1816 次 / 40 个会话、`comfyui-local` 5 次 / 5 个会话、`huashu-design` 0 次（如实显示「会话里没有直接调用过它」）。统计一次要扫 173MB 转写（≈4s），所以结果在进程内缓存 5 分钟。

**快捷键 `?`**：唤出一张浮层，列全 `/`（搜索）、`↑↓`（结果走位）、`1/2/3`（三档视图）、左键拖（平移 / 转视角）、中键•右键拖（纯平移，不误选）、`Shift`+点两下（证据链）、`e`（把选中拉到面前）、`r`（重建）、`Esc`（关证据链 / 详情）。点一下浮层就收。

## 区块加载（星云是「长」出来的）

学 Minecraft 的做法：**世界切格子、按离视口远近排队、每帧只点亮一点**，而不是「等整包 → 一次性蹦出来」。

- **传输瘦身**（P0 → P1）：`/graph` 不再发长 id 和正文摘要——边改成「节点下标」`{s,d,w,t,curated}`，节点只留绘制必需的 12 个字段（`label` 截 46 字、去掉 `preview/title/keywords/entities`）。实测 **2,646,434 字节 / 1895ms → 831,444 字节 / 681ms**（-69% / -64%），浏览器里量到 `graphMs 33–73ms`、首帧 `41–85ms`。正文、关键词、邻居、出处这些**照样按需**走 `/node`，不占首屏。
- **按格点亮**：世界坐标按 900 单位切格，格子按「离视口中心距离」排序，每格错开 110ms，格内按重要度先亮 → 屏幕上是「一波从中心向外铺开」的生长，而不是整片闪出。所有节点约 **1.7s** 长满（`doneMs 1668–1717`）。
- **边等底子**：一条边要两端都亮到 85% 才画，并按剩余 15% 渐显——所以不会出现「先有线、后有点」的鬼影。
- **每帧预算**：力导向不抢帧，每帧只花 8ms 推进，最多 420 轮；点亮与布局并行，画面一边长一边自己找位置。
- **进度可见**：遮罩上给「正在生长记忆星云… 916 / 1354 条记忆 · 68%」+ 渐变进度条；长满自动淡出。`window.__nebulaBoot` 记录 `graphMs / firstDrawMs / doneMs`，量性能直接读它。

## 记忆体检（从 luanyujia-workbench 学来的一节）

参考项目 [luanyujia-workbench](https://github.com/mashanglinyu/luanyujia-workbench) 把「记忆失效模式」写成了一张表：越写越肥没人读、两份数字打架、体积正常但没用、拿历史数字判断现在。它靠**人守纪律**避免这些；星图手里有全量正文和度数，可以直接把它们**查出来**。

- 位置：左侧「记忆来源」面板里的 `记忆体检 N 项`，点开展开分组；点某一条直接跳到那条记忆。
- 六项检查（`lib/host/graph.js` 的 `auditHygiene`）：
  - **疑似重复**：正文稀有词签名 Jaccard ≥ 0.86 且长度比 ≥ 0.6 —— 两条在说同一件事。
  - **该更新了**：还挂 `active`，但同项目里有更新、更重要、共享 ≥3 个关键词的记忆覆盖了它。
  - **关系是凑的**：度数 ≥10 但平均边权 <0.45 —— 连接多而都弱，多半是关键词撞出来的。
  - **超重**：正文长度超过「本库最重的 3%」（下限 600 字）——读一次就吃掉一截上下文。
  - **没人读过**：写下 3 天以上、`hit_count` 为 0、还是 active。
  - **孤立**：一条边都没有。
- 阈值不写死：体量类按当前库的分位数算，所以记忆还小的时候不会满屏报警。
- **只诊断，不改任何记忆**——它给的是清单，改不改由人（或 AI）决定。
- 两个出口：界面上的看板「体检」页，和会话里的工具 `nebula_hygiene(kind?, limit?)`（可按 `dup / stale / thin / oversize / unread / orphan` 只看一类，每条都带 id，方便接着用 `nebula_inspect`）。

## 四块看板 / 命令面板 / 主线

界面这一层在 v0.4 补了三件「不用翻详情就能看全局」的东西，全部零后端改动（数据都来自已有的 `/overview`、`/node`、`/recall`）：

- **看板**（顶栏「看板」或按 `B`）：四页签，对应 luanyujia 那套「四块板」的意图，但只做**读**：
  - 来源：每个记忆库多少条（点一行＝星图只看那个项目）、已装插件 / 记忆类 / MCP / 技能计数，以及外部记忆源的真实状态（Hindsight 没 token 就写「暂不可读」，OpenViking 只有待上传队列也照实说）。
  - 真源：只挑正文里明确写了「以…为准 / 单一真源 / 唯一权威」的记忆，按项目分组——**不做语义猜测**，宁可少列也不给你一堆要判断的假冲突。
  - 体检：六项失效模式分组的清单，点一条直接打开。
  - 屏蔽：所有被 `mute` 的关联对，一键恢复。
- **命令面板**（`Ctrl/⌘ + K`）：先列命令（切三档视图、开项目卡片、开四块看板、重建、聚焦选中），继续打字就同时搜记忆；`↑↓` 选、`Enter` 执行、`Esc` 关。
- **主线**（选中一条记忆后按 `L`）：把「同一次会话里按时间最接近的 12 条」排成一条时间线，看清这条想法当时前后在聊什么；底部注明同会话总数。
  时间轴里包含**当前这条**并高亮（右侧写「当前」），跨天处有日期小标题，标题与页脚都带真实条数。
- 详情里还多了两行：**重要度建议**（`3 → 4（被读过 12 次，连了 15 条）`，只建议不改库）和**落库时算出的证据**（第一次建图就把 top-3 证据写进 sidecar 缓存，之后开详情不必现算）。

## 两种「看得清」的手段

- **LOD 聚合**：簇在屏幕上的半径小于 96px 时，整团收成一个光斑（带条数与项目名），点它就把镜头推进去散开。远看是星团、近看是星点，不再一堆糊在一起的标签。
- **pan 预取**：簇的世界坐标包围盒算一次缓存起来，拖动时每帧只投 4 个角，不再每帧遍历上千节点。这是 LOD 能稳的前提，也让拖动一直 60fps。
- **3D 区块点亮**：星系视图也走「长出来」——按簇排队、簇内重要度高的先亮，1.6s 内铺满；顶栏进度条在两种视图都显示。

## 别让人掉进「看不见 / 回不去」

筛选和聚焦本来是为了看清，但它们也能把人困住：筛到只剩几条、连接全被过滤掉、或者镜头推进某个簇以后不知道怎么退回来。所以这一层专门加了三条退路：

- **常驻的「重置筛选 · 回全视图」**（筛选面板顶部）：一键清空所有筛选，并把镜头拉回能看见全部记忆的位置。
- **筛选代价提示**：只要有筛选生效，就在按钮下面写清「已筛选：隐藏 N 条记忆（共 M 条连接）」，弱连接阈值也一并标出——不让「图怎么空了」变成猜谜。
- **三条回全视图的入口**：`F` 键、双击画布空白处（拖拽/双击节点不会误触）、顶栏「聚焦」按钮。3D 的 `fit` 会把 yaw/pitch/平移一起复位，不是只改距离。

## 这一轮加的东西（项目卡片 / 看板 / 命令面板 / 主线 / 体检 / LOD）

- **项目卡片（P 或顶栏「项目」）**：每个工作区一张卡——条数、层级分布、会话数、最近三条变更、下一步待办、代表记忆（度数最高的三条）、体检结果。点卡片左上角工作区名可以把星云筛到那个项目。
- **四块看板（B 或顶栏「看板」）**：来源 / 真源 / 体检 / 屏蔽。真源只认正文里明写「以…为准 / 单一真源 / 唯一权威」的记忆，不做语义猜测——宁可漏也不编。
- **命令面板（Ctrl+K）**：切视图、开面板、搜记忆混在一起；输入即走 recall，回车直接打开那条记忆。
- **主线（选中记忆后按 L）**：把同一会话里时间上离它最近的记忆按时间排开——看得出「这个想法是从哪儿长出来的」。
- **记忆体检（nebula_hygiene 工具 / 看板体检页）**：六类失效模式（重复、该更新了、关系是凑的、超重、没人读过、孤立），只诊断不改别人的库。
- **LOD 聚合**：簇在屏幕上小于 96 px 时整团收成一个光斑（带条数和项目名），点一下推近展开；世界坐标包围盒做了缓存，拖动时不再每帧遍历全图。
- **区块点亮（3D 也有）**：星云和星系都是按「格 / 簇」错峰亮起来的，顶栏进度条同步显示「正在生长…」。
- **不会掉进「看不见 / 回不去」**：筛选面板顶部常驻「重置筛选 · 全视图」，F 回全视图、Shift+F 清筛选、双击空白也回全视图。
- **写这条记忆时主人说的话**（记忆出处）：从 141 个会话转写里取该记忆写入前 45 分钟内最晚一条真人消息，挂在详情顶部，只作旁证、不参与连边。

实测（2026-11-07，1500+ 条记忆）：/graph 831 KB（v2 精简后），点卡片可筛到单个项目；LOD 在 k≈0.25 时把 Rustfare（16 条）收成一个斑，focusCluster 后 k 推到 2.1 自动散开。

## 0.2.0：能拖着看，也能带走

这一版没有加新概念，只把「已经能看见的东西」变得可操作、可交付。

- **时间回放（螺旋视图底部时间轴）**：往左拖，只留下「那一天及之前的记忆」，连线按同一时刻一起收；
  右侧实时显示「≤ 10-31 · 635 条」，双击时间轴回到全部。闸门只有一处——`space3d.visible()`，
  所以聚类视图、筛选、证据链、LOD 全都遵循同一个「可见」定义，不会出现「点看不见但边还在」。
- **导出（顶栏「导出」）**
  - `当前视图 · PNG`：把当前画面拼成带标题栏的图（记忆 / 连接 / 工作区 / 时间戳）。界面元素不进图；
    2D 出图时临时收掉给侧栏留的空白再重新居中，导出的图不会一半是空的。
  - `可见子图 · JSON`：当前筛选下看得见的节点与边，写成 `memory-nebula/subgraph@1`，
    含 filter 与 stats，方便拿去做外部统计或喂给别的工具。
- **左栏分组可折叠**：工作区 / 记忆层级 / 连接类型 / 两根滑杆 / 记忆来源都能收起，状态记在 `localStorage`。
  小屏上把「连接类型」收起来，图就露出来了。
- **点哪都能定位**：搜索、看板、详情里的邻居、体检项——点一条记忆，不在视口里就把镜头缓动带过去，
  本来就在视口里就不动镜头（避免点一下画面就跳）。定位会避开左右面板，节点不会藏在侧栏底下。
- **降级不再完全静默**：`overview / recall / path / align` 第一次失败会留一条 `console.debug`；
  来源面板读不到会直接写「来源读不到：…」，不是空着让人猜。
- **详情头部「复制 id / 复制会话」**：一条记忆要带去别处时，先拿得到它的身份。
  （点进会话的深链要等宿主开放路由，这一版只保证 id 拿得到。）
- **失败态**：首屏连不上接口时不再甩原始报错，而是「连不上记忆库 / 需要从 DSH 打开 / 取图失败」三种人话说明 + 重试（原地接上，不刷新）+ 复制诊断，技术细节收在折叠里。
运行中接口断开会温柔一点：顶部一条细提示「接口断开了 · 正在重试…」，两条腿（宿主 / 独立引擎）都不通才出现，恢复后自动消失。
- **一致性**：螺旋视图的时间闸门不只画在画面上——「导出可见子图」也认它（写进 `filter.until`），
  重建后时间轴范围会跟着新图重算，不会出现「图里没有、导出却有」。
- **`scripts/smoke.mjs`**：只读接口契约自查，随包发布。`node scripts/smoke.mjs` 全绿才算能发；
  它专门盯住「`refresh` 与 `graph` 必须同构」——历史那次丢线，就出在这条上。

## 0.3.0：来源变多了，界面要说得清

这一版后台多了适配器与补充包，界面只需要回答一个问题：**这条记忆是谁给的。**

- **「记忆来源」筛选组**：按 `provider` 分（`meow-memory` / `inventory` / 你新接的笔记目录、SQLite、ingest）。
  只有**接了两种以上来源**时才出现——单来源时一颗 chip 只是噪音。chip 的圆点用 `providerColor()` 取色：
  认识的来源用固定色（meow 青、环境灰），不认识的按字符串哈希生成一个稳定的 hsl，接十个来源也不会撞色。
- **详情页的来源徽章**：非 `meow-memory` 的节点，在层级/工作区标签后面多一枚「来源 · <名字>」，
  颜色同上。一眼能看出「这条是笔记库里读来的，不是记忆库」。
- **顶部卡片改名「记忆概览」**：原来的「记忆来源」标题让位给新的筛选组，卡片本身讲的是规模
  （记忆库 / 已装插件 / 记忆类插件 / 技能 / MCP / 已屏蔽关联 / 体检项）。
- **左栏收紧**：宽度 246 → 266px，四组筛选（来源 / 工作区 / 层级 / 连接类型）在 1000px 高的窗口里
  全部放得下，底部还露出「最小连接强度」滑杆；面板间距、chip 高度、滚动条都收了一档。
- **精修层**：字体栈补 HarmonyOS Sans SC / Microsoft YaHei UI；所有数字用 `tabular-nums`（统计跳动时不对齐会抖）；
  面板加 1px 内高光；按钮 `:active` 轻微下压、`:focus-visible` 双环；chip 选中内发光；
  `.hit` / `.nbr` 左侧 2px 渐变色条 hover 显形；首屏 0.5s 一次性入场（顶栏 → 搜索 → 左栏 → 图例，错峰）；
  `prefers-reduced-motion` 下全部关掉。

### 窄屏（≤900px）

左列默认收起，顶栏出现「筛选」按钮：点开是抽屉式面板（工作区 / 层级 / 连接类型 / 两根滑杆），
点面板外或按 Esc 收回。统计只留「记忆 / 连接 / 工作区」三项，避免标签互相压。三种视图仍是同一套筛选。
