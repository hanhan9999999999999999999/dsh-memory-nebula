# 出问题时先看这里

这份文档按「最可能先撞到」的顺序排。能自己定位的，不用等回复；需要贴给支持的，
尽量带上 `doctor` 的输出，不要带记忆正文。

## 1. 先跑一次安装体检

```bash
node scripts/doctor.mjs --profile <你的 DSH profile 目录>
# 连正在运行的实例一起测
node scripts/doctor.mjs --profile <profile> --base http://127.0.0.1:7890/api/memory-nebula
```

- 8–9 项全过：安装、依赖、bundles、Node 版本、来源和端点都没问题。
- `[warn] version`：装的是新版本，但宿主还跑着旧代码；见下一节。
- `[fail] profile` / `bundle`：插件没有真正启用，先修 profile，不要继续查图。

`--json` 给工单系统，`--lang en` 给英文支持。

## 2. 顶部出现「宿主还是旧代码」

`lib/host/http.js`、`index.js`、`live.js` 是静态加载的，**刷新页面不会换掉后端**。
需要重启 DSH（或改用 standalone），让宿主重新加载插件。重启后再跑一次 `doctor`，
`version` 那一条应该消失。

不要为了消掉横幅去反复重装包；先确认 `doctor` 里 `installed` 和 `endpoint` 的版本。

## 3. 页面空白 / 一直转圈

1. 直接访问 `http://127.0.0.1:<端口>/api/memory-nebula/ping`。返回 `ok:true` 说明后端活着。
2. 如果是在 DSH 里打开：确认是从侧栏/插件入口进，不是把 `index.html` 拖进浏览器。
3. 页面上的「复制诊断」会给出版本、模式、图规模、WebGL 和最近错误；先复制，再刷新。
4. 仍然空白：看 DSH 日志里 `memory-nebula` 的 `lastError`，或跑 `standalone --diagnose`。

## 4. 图是空的

- 左栏「记忆来源」是否只有「示例」或 0 条？先写几条记忆，再点「重建星图」。
- 想先看长什么样：空态里的「看示例」；示例是虚构数据，不读写你的库。
- 自己的库没被扫到：看 `docs/adapters.md`，确认 `.dsh-meow/memory.db` 或笔记根目录在扫描范围内。
- 命令行可用 `--root` 指定目录；不要同时开多个实例抢同一个端口。

## 5. 3D 按钮点了没反应 / 被拒绝

超过 3,000 条会主动留在二维星云，提示「先在二维里看，筛选到 3000 条以内再切」。
这不是故障：软件渲染下 20k 点 + 15 万边切 3D 会卡死。先按工作区/层级筛选，或直接
用二维和证据链。

## 6. 单文件快照很大、第一次打开慢

`/share` 会把范围内的**正文**一起写进 HTML，所以文件天然比图大：

- 20k 全量约 23MB；全新 profile 第一次打开约 4.7s，热缓存约 0.95–1.1s。
- 分享前先用「当前工作区」或「选中节点 2 跳」，再勾「隐去日记」。
- 收件人不需要装 DSH；双击 HTML 即可，搜索和证据链在本地算。
- 快照是时间点副本，不会随原库更新；要更新就重新导出。

## 7. 分享会不会带出隐私

- `/share` 是正文出口；`scope` 决定范围，`hide` 决定排除哪些层级/工作区/项目/状态。
- 来源列表只保留 key/title/size/kind/count，不含本机路径；`inventory` 仍会带插件/技能名称清单。
- 不确定时先导一份小的，自己打开搜索一下敏感词，再发。
- standalone 没有账号系统；不要把端口暴露到公网。

## 8. 搜索没有结果

- 先换一个你确定写在正文里的词；只有标题/关键词命中也会算，但不会凭空造关联。
- 空态里的「没认出的词」表示分词表里没有它；换一个更短、更常见的词。
- 试试左栏只留一个工作区，或点「看示例」确认界面本身正常。
- 详情里的「扩散」不是搜索：它只沿已有连接走 2 跳。

## 9. 端口冲突 / 起不来

```bash
node lib/standalone.mjs --port 7891 --root "D:/document/Memory Universe"
```

默认 7890；sidecar 会按端口隔离。端口被占用时换一个，不要同时起两个实例写同一个
`$DSH_HOME/memory-nebula`。

## 10. Node 版本

要求 Node `>=22.13.0`。低于这个版本，`doctor` 第一条就会 fail；升级 Node 后重装包，
不要只替换 `node_modules` 里的一个文件。

## 11. 提交问题时带什么

- `doctor` 的文本或 `--json` 输出（不含正文）；
- 插件版本、DSH 版本、Node 版本、操作系统；
- 复现步骤：从哪个入口打开、点了什么、期望什么、实际什么；
- 页面「复制诊断」的内容；必要时加一张截图。

不要贴整份记忆库、token、`.npmrc` 或带正文的快照。
